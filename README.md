# Prime Dev Force plugins for Claude

Free Claude plugins from [Prime Dev Force LLC](https://coverageclock.primedevforce.com/about.html), the publisher of [Coverage Clock](https://coverageclock.primedevforce.com/).

## Install in Claude Code

```
/plugin marketplace add syedemazali-alt/prime-dev-force-plugins
/plugin install home-insurance-navigator@prime-dev-force-plugins
```

## Install in claude.ai or the Claude desktop app

Open Customize > Plugins > Add > Add marketplace, enter `syedemazali-alt/prime-dev-force-plugins`, then add Home Insurance Navigator.

## Plugins

- **Home Insurance Navigator**: help for U.S. homeowners with non-renewals, FAIR Plans and coverage questions. See [its README](plugins/home-insurance-navigator/README.md).

Homeowner help hub: [Home Insurance Non-Renewal Help](https://sites.google.com/view/non-renewal-help-hub), a companion site with guides and links to Coverage Clock.
